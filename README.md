# Yellow Taxi Power BI Dashboard

Power BI dashboard project analysing Yellow Taxi trip data.

## Project Overview

This project focuses on analysing taxi trip data through an interactive Power BI dashboard. The goal is to explore trip volume, revenue, passenger behaviour, payment methods, and time-based patterns.

## Objectives

- Analyse taxi trip data
- Create key performance indicators
- Build an interactive Power BI dashboard
- Identify patterns in revenue, trips, passengers, and payment methods
- Support business insights through data visualization

## Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization
- Dashboard Design
- KPI Reporting

## Key Analysis Areas

- Total trips
- Total revenue
- Average fare
- Passenger count
- Payment methods
- Trips by time period
- Revenue trends
- Trip distance analysis
